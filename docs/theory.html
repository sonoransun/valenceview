The mathematics behind Valence View

1. Overview & honesty statement

Every orbital drawn by the app is a hydrogen-like wavefunction: an exact solution of the one-electron Coulomb problem, evaluated with an effective nuclear charge Zeff obtained from Slater's screening rules. This page states, formula by formula, exactly what the code computes — same conventions, same normalizations, same constants. The verification suite checks these statements numerically in your browser, including a theory-anchors group that compares the closed-form tables printed on this page against the program's independently generated symbolic coefficients.

What the model captures well: orbital shapes, nodal structure, degeneracy patterns, and periodic trends in size and binding. What it does not capture: electron–electron correlation, exchange, self-consistency, relativity, or spin. It is the standard teaching model of atomic structure — quantitatively rough for many-electron atoms, and honest about it (see §8). The magnetic-field and companion-element modes are first-order estimates and are labeled Speculative both here and in the app.

Conventions used throughout this page and the code: lengths in Bohr radii (a0 = 52.9177 pm), energies in electron-volts, magnetic field in tesla; r is always dimensionless (units of a0) and Z denotes Zeff unless stated otherwise. The magnetic-field and bond axis is always the global +z axis — the renderer rotates the scene, never the physics.

2. The Schrödinger equation

A single electron bound to a point charge +Ze obeys the time-independent Schrödinger equation

[ − ℏ22me ∇2 − Ze24πε0r ] ψ = Eψ [ -hbar^2/(2 m_e) nabla^2 - Z e^2/(4 pi eps0 r) ] psi = E psi

In Hartree atomic units (lengths in a0, energies in hartree; 1 hartree = 2 Ry = 27.2114 eV) this collapses to

( −12∇2 −Zr ) ψ=Eψ ( -(1/2) nabla^2 - Z/r ) psi = E psi

which is the form the rest of this page uses. The Coulomb potential is central — it depends only on r — which is what makes an exact separation into radial and angular factors possible.

3. Separation of variables

In spherical coordinates (r, θ, φ) the ansatz

ψnlm (r,θ,φ) = Rnl(r) Ylm (θ,φ) psi_nlm(r, theta, phi) = R_nl(r) * Y_l^m(theta, phi)

splits the equation into an angular eigenvalue problem whose separation constant is l(l+1), solved by the spherical harmonics (§4), and a one-dimensional radial equation

− 12r2 ddr ( r2 dRdr ) + [ l(l+1)2r2 − Zr ] R = ER -(1/(2 r^2)) d/dr ( r^2 dR/dr ) + [ l(l+1)/(2 r^2) - Z/r ] R = E R

solved in §6. Square-integrability quantizes the solutions: the principal quantum number n = 1, 2, 3, …; the orbital quantum number l = 0 … n−1 (letters s, p, d, f); and the magnetic quantum number m = −l … +l. Normalization is split conventionally as

∫0∞ r2 Rnl2 dr =1 , ∫ |Ylm|2 dΩ =1 integral_0^inf r^2 R_nl^2 dr = 1 , integral |Y_l^m|^2 dOmega = 1

so that each factor is separately normalized — exactly the two integrals the verify suite evaluates.

4. Angular solutions: associated Legendre and spherical harmonics

The code computes associated Legendre functions in x = cos θ with the Condon–Shortley phase (−1)m included inside Plm (the physics convention), using the standard stable recurrence:

Pmm(x) = (−1)m (2m−1)!! (1−x2)m/2 P_m^m(x) = (-1)^m (2m-1)!! (1 - x^2)^(m/2) Pm+1m(x) = (2m+1) x Pmm(x) P_(m+1)^m(x) = (2m+1) x P_m^m(x) (l−m) Plm(x) = (2l−1) x Pl−1m(x) − (l+m−1) Pl−2m(x) (l - m) P_l^m(x) = (2l-1) x P_(l-1)^m(x) - (l+m-1) P_(l-2)^m(x)

The complex spherical harmonics are then, for m ≥ 0,

Ylm (θ,φ) = Nlm Plm (cosθ) eimφ , Nlm = 2l+14π · (l−|m|)! (l+|m|)! Y_l^m(theta, phi) = N_lm P_l^m(cos theta) e^(i m phi) , N_lm = sqrt( (2l+1)/(4 pi) * (l-|m|)!/(l+|m|)! )

with negative orders defined by conjugation:

Yl−m = (−1)m (Ylm)* Y_l^(-m) = (-1)^m conj(Y_l^m)

5. Real orbitals: the chemistry combinations

The orbitals chemists draw — px, dxy, … — are the real linear combinations Sl,m of the ±m pairs. With the Condon–Shortley phase already inside Plm, the code uses

Sl,0 = Nl0 Pl0 (cosθ) S_(l,0) = N_l0 P_l^0(cos theta) Sl,m = 2 (−1)m Nlm Plm (cosθ) cosmφ (m > 0) S_(l,m) = sqrt(2) (-1)^m N_lm P_l^m(cos theta) cos(m phi) (m > 0) Sl,−m = 2 (−1)m Nlm Plm (cosθ) sinmφ (m > 0) S_(l,-m) = sqrt(2) (-1)^m N_lm P_l^m(cos theta) sin(m phi) (m > 0)

Equivalently, in terms of the complex harmonics — this identity fixes the relative signs, and it is what makes the Larmor-precession result of §9 exact:

Sl,m = (−1)m Ylm + Yl−m 2 , Sl,−m = (−1)m Ylm − Yl−m i2 (m > 0) S_(l,m) = ((-1)^m Y_l^m + Y_l^(-m)) / sqrt(2) , S_(l,-m) = ((-1)^m Y_l^m - Y_l^(-m)) / (i sqrt(2)) (m > 0)

The app's canonical orbital keys map m to suffixes as follows. p: m = +1 → x, −1 → y, 0 → z. d: 0 → z2, +1 → xz, −1 → yz, +2 → x2y2, −2 → xy. f: 0 → z3, +1 → xz2, −1 → yz2, +2 → zx2y2, −2 → xyz, +3 → xx23y2 (fx(x²−3y²)), −3 → y3x2y2 (fy(3x²−y²)). So 3d_z2 is 3dz² and 4f_xyz is 4fxyz.

Real vs. complex display. The orbital chips always select real orbitals. A real orbital is a stationary state here, so its density is time-independent; only its global phase evolves, as arg ψ(t) = −(E/ℏ)t. When the app's color mode is phase and |m| > 0, the view switches to the complex partner eimφ whose phase pattern visibly circulates: arg ψ(t) = mφ − (E/ℏ)t. Real physical periods are of order 10−16 s; the animation applies a display time-scale factor, which the app reports.

6. Radial solutions: generalized Laguerre polynomials

The code uses the modern generalized-Laguerre convention (Abramowitz & Stegun; later editions of Griffiths):

Lk(α) (x) = Σi=0k (−1)i ( k+αk−i ) xii! L_k^(alpha)(x) = sum_(i=0)^k (-1)^i binom(k+alpha, k-i) x^i / i!

Convention warning: older quantum-chemistry texts use an associated-Laguerre definition that differs by a factor of [(k+α)!] and an index shift; formulas mixed between conventions produce wrongly normalized orbitals. Everything below (and in the code) is consistent with the definition above, and the normalization is confirmed numerically by the radial-norm checks.

With the scaled radius

ρ= 2Zrn (r in units of a₀) rho = 2 Z r / n (r in units of a0)

the normalized radial function is

Rnl(r) = Nnl e−ρ/2 ρl Ln−l−1(2l+1) (ρ) R_nl(r) = N_nl e^(-rho/2) rho^l L_(n-l-1)^(2l+1)(rho) Nnl = (2Zn)3 (n−l−1)! 2n(n+l)! N_nl = sqrt( (2Z/n)^3 (n-l-1)! / (2n (n+l)!) )

The Laguerre factor is a degree-(n−l−1) polynomial, giving exactly n−l−1 radial nodes. The code generates the polynomial coefficients as exact BigInt rationals and evaluates by Horner's rule; an independent three-term recurrence cross-checks every value (laguerre-xcheck).

7. Energies and expectation values

The hydrogenic energy depends only on n:

En = − Z22n2 hartree = −13.605693 Z2n2 eV E_n = -Z^2/(2 n^2) hartree = -13.605693 Z^2/n^2 eV

Useful closed forms, all implemented and all verified against numerical quadrature (r in a0, Z = Zeff):

⟨r⟩ = 3n2−l(l+1) 2Z <r> = (3 n^2 - l(l+1)) / (2 Z) ⟨r2⟩ = n2(5n2+1−3l(l+1)) 2Z2 , ⟨r−1⟩ = Zn2 <r^2> = n^2 (5 n^2 + 1 - 3 l(l+1)) / (2 Z^2) , <1/r> = Z/n^2

For the node-less orbitals l = n−1 (1s, 2p, 3d, 4f) the most probable radius — the peak of the radial density P(r) = r²R² — has the exact value

rmp = n2Z (l = n−1) r_mp = n^2/Z (l = n-1)

used as a verification anchor for the general numerical peak-finder. Node counts: n−l−1 radial nodes (spheres) and l angular nodes; for a real orbital the angular nodes split into |m| planes and l−|m| cones. The info panel reports all of these for the selected orbital.

8. Slater screening: Zeff for many-electron atoms

For a many-electron atom the app draws the valence orbital as a hydrogenic function with effective charge Zeff = Z − s, where the screening constant s follows Slater's 1930 rules [3]. Electrons are grouped in the fixed order

1s | 2s,2p | 3s,3p | 3d | 4s,4p | 4d | 4f | 5s,5p | 5d | 5f | 6s,6p | 6d | 7s,7p

and each other electron contributes to s:

  • For an electron in an ns,np group: 0.35 per other electron in the same group (0.30 if the group is 1s); 0.85 per electron with principal quantum number n−1; 1.00 per electron in n−2 or deeper shells.
  • For an electron in an nd or nf group: 0.35 per other electron in the same group; 1.00 per electron in every earlier group — including the same-n s,p electrons.

All constants are exact multiples of 1/20, so the code carries Zeff as an exact rational. Slater pairs the screening rule with an effective quantum number n*:

Slater's effective principal quantum number. n* for n = 7 is extrapolated (flagged in the code).
n1234567
n*1233.74.04.24.3

The app reports two energy estimates per orbital, clearly labeled:

ESlater = −13.605693 (Zeffn*) 2 eV , Ehyd = −13.605693 Zeff2n2 eV E_Slater = -13.605693 (Z_eff/n*)^2 eV , E_hyd = -13.605693 Z_eff^2/n^2 eV

The hydrogenic one uses integer n and matches the wavefunction actually drawn; the Slater one is his original energy estimate with n*.

Worked example: iron (Z = 26, [Ar] 3d⁶ 4s²)

Grouped configuration: (1s)² (2s,2p)⁸ (3s,3p)⁸ (3d)⁶ (4s,4p)².

For a 3d electron (d-group rule — everything below 3d counts 1.00):

s= 5(0.35) + 18(1.00) =19.75 ⇒ Zeff =26−19.75=6.25 s = 5(0.35) + 18(1.00) = 19.75 => Z_eff = 26 - 19.75 = 6.25

For a 4s electron (s,p-group rule — one 4s partner at 0.35, the fourteen n = 3 electrons at 0.85, the ten n ≤ 2 electrons at 1.00):

s= 1(0.35) + 14(0.85) + 10(1.00) =22.25 ⇒ Zeff =26−22.25=3.75 s = 1(0.35) + 14(0.85) + 10(1.00) = 22.25 => Z_eff = 26 - 22.25 = 3.75

So Fe 3d is computed with Zeff = 6.25 (Ehyd = −13.605693 · 6.25²/9 ≈ −59.05 eV, ⟨r⟩ = 21/12.5 = 1.68 a₀ ≈ 88.9 pm) and Fe 4s with Zeff = 3.75 (Ehyd ≈ −11.96 eV, ESlater with n* = 3.7 ≈ −13.98 eV). These exact rationals are asserted by the slater-regression verify check.

Honest limitations

  • No l-dependence within an s,p group. Slater's rules give identical Zeff for ns and np — wrong in detail (real s electrons penetrate more and are bound more tightly).
  • Valence s underestimated. Compared to the SCF-derived screening constants of Clementi & Raimondi [4], Slater's Zeff for 4s and heavier valence s orbitals is badly low — K 4s: Slater 2.20 vs. Clementi 3.50. The slater-vs-clementi check reports these deviations as informational rows rather than hiding them.
  • No relativity. Increasingly wrong past Z ≈ 70 (this is why gold is gold-colored and mercury is liquid — effects entirely absent here). Superheavy elements are decorative, and their configurations (Z ≥ 104) are themselves predictions, flagged in the app.
  • Subshells are not mutually orthogonal. Because each subshell gets its own Zeff, same-element orbitals from different subshells (e.g. Fe 3d with Z = 6.25 and Fe 4s with Z = 3.75) are not orthogonal, unlike true eigenstates of one Hamiltonian. The subshell-nonortho check measures and reports this overlap rather than pretending it vanishes.

9. Magnetic field: Zeeman shifts, Larmor precession, squeeze

SPECULATIVE First-order orbital Zeeman model only: electron spin, spin–orbit coupling, and the true quadratic Zeeman eigenstates are all omitted. The squeeze factor below is an interpolating heuristic, not a solution of the strong-field problem.

With the field B along +z, the orbital Zeeman term (μB/ℏ) B Lz is diagonal in the complex basis, giving the linear shift

ΔEm = μB Bm , μB = 5.788382×10−5 eV/T Delta E_m = mu_B B m , mu_B = 5.788382e-5 eV/T

The 2l+1 levels of a subshell split symmetrically — Σm ΔEm = 0, asserted by the zeeman-sym check. The associated Larmor frequency is

ωL = μBBℏ ≈ 8.794×1010 B rad/s (B in tesla) omega_L = mu_B B / hbar ~= 8.794e10 * B rad/s (B in tesla)

Precession of real orbitals (exact within the linear model). A real orbital with |m| = μ > 0 is a fixed combination of Yl+μ and Yl−μ (§5). Under the field the two components acquire opposite phases e∓iμωLt beyond the common e−iEt/ℏ, and the combination reassembles exactly into

ψ(t) ∝ Rnl(r) Nlμ Plμ (cosθ) cos ( μ (φ−ωLt) ) psi(t) ∝ R_nl(r) N_l,mu P_l^mu(cos theta) cos( mu (phi - omega_L t) )

(cos-type shown; sin-type is analogous): the density pattern rotates rigidly about z at ωL, independent of μ. Orbitals with m = 0 neither shift nor precess. Real rates are fast — at 10 T one revolution takes about 7.1 ps — so the app applies a display speedup factor and says so.

Strong-field squeeze (heuristic). The neglected diamagnetic term (e²B²/8me)(x²+y²) compresses the orbital perpendicular to the field. Defining the cyclotron-to-binding ratio

γ = μBB |Enl| , s⊥ = (1+γ2) −1/4 gamma = mu_B B / |E_nl| , s_perp = (1 + gamma^2)^(-1/4)

the drawn orbital is squeezed norm-preservingly in the transverse directions:

ψB (x,y,z) = 1s⊥ ψ ( xs⊥, ys⊥, z ) psi_B(x, y, z) = (1/s_perp) psi(x/s_perp, y/s_perp, z)

Validity, honestly. The formula is exact in both limits: s⊥ → 1 as B → 0, and s⊥ ∝ B−1/2 — the magnetic-length scaling √(ℏ/eB) — in the Landau regime. In between it is only an interpolation (squeeze-limit-b0 and squeeze-limit-binf check both ends). Reaching γ ≈ 1 requires B ~ 10⁴–10⁵ T: white-dwarf and neutron-star territory, far beyond any laboratory field. And the true strong-field eigenstate is a field-elongated "cigar", which this transverse squeeze only qualitatively imitates. That is why this whole section — and the app's field panel — carries the SPECULATIVE label.

10. Two-center LCAO: bonding, antibonding, hybrids

SPECULATIVE Frozen-atomic-orbital LCAO with no self-consistency; energies are Wolfsberg–Helmholz estimates. Shapes are meaningful; numbers are indicative.

The companion mode places nucleus A at (0, 0, −R/2) and B at (0, 0, +R/2) (R in a0, user-adjustable 0.5–10). Each atom contributes a valence orbital with its own Slater Zeff and on-site energy α = ESlater. The molecular orbital is the linear combination cAφA + cBφB with the signed overlap integral

S = ∫ φA φB d3r S = integral phi_A phi_B d^3r

evaluated in cylindrical coordinates (the azimuthal factor is analytic; the model evaluates σ pairs, mA = mB = 0, and π pairs, |m| = 1 of the same real type; pairs of differing |m| or mixed cos/sin type vanish by symmetry, while δ-type pairs (|m| = 2, same real type) have nonzero overlap on-axis but are treated as nonbonding here — a documented simplification). The off-diagonal element uses the Wolfsberg–Helmholz prescription [5] with the conventional k = 1.75:

β = 1.75 S αA+αB 2 beta = 1.75 S (alpha_A + alpha_B)/2

Energies come from the 2×2 secular problem with overlap:

det [ αA−E β−ES β−ES αB−E ] =0 det [ [alpha_A - E, beta - E S], [beta - E S, alpha_B - E] ] = 0

a quadratic in E whose lower root E− is the bonding MO and upper root E+ the antibonding MO. For each root the coefficient ratio and normalization are

cBcA = − αA−E β−ES , cA2 + cB2 + 2cAcBS =1 c_B/c_A = -(alpha_A - E)/(beta - E S) , c_A^2 + c_B^2 + 2 c_A c_B S = 1

Sign convention. Both atoms use global-frame orbitals. For a pz–pz σ pair the facing lobes then have opposite global signs, so the bonding combination is φA − φB. The solver gets this right automatically because S is kept signed throughout — nothing in the code takes |S|. Heteronuclear polarity also falls out: the atom with larger |α| takes the larger bonding coefficient (e.g. HF), and the app's info panel displays cA and cB for both MOs; by the normalization above these split the electron population into cA², cB², and the overlap term 2cAcBS. Limiting behavior (S → 1 as R → 0 for identical 1s with Zeff = 1; agreement with the closed form S(R) = e−R(1 + R + R²/3) at R = 2 and 8 a₀, where S(8 a₀) ≈ 0.0102; Ebond < α with cA = cB for H₂ at R = 1.4) is asserted by the lcao-s-r0, lcao-s-r2, lcao-s-r8, and mo-homonuclear checks.

11. Superstructures: Hückel chains and rings

SPECULATIVE Nearest-neighbor Hückel model on frozen atomic orbitals; the same caveats as §10 apply, plus the topology itself is idealized.

The cluster mode extends the two-center picture to small symmetric N-atom chains and rings (N ≤ 6) using the Hückel approximation: every atom carries one basis orbital with on-site energy α, only nearest neighbors couple with hopping β (left symbolic — the app reports levels as (E − α)/β, in units of β; the spacing control sets geometry only), and overlap is dropped from the eigenproblem. These topologies have closed-form eigenpairs, so no general eigensolver is involved. For a chain of N atoms:

Ek = α+2β cos kπN+1 , ckj = 2N+1 sin jkπN+1 , k=1…N E_k = alpha + 2 beta cos( k pi/(N+1) ) , c_kj = sqrt(2/(N+1)) sin( j k pi/(N+1) ) , k = 1..N

For a ring of N atoms:

Ek = α+2β cos 2πkN , k=0,±1,±2,… E_k = alpha + 2 beta cos( 2 pi k / N ) , k = 0, ±1, ±2, ...

with the levels ±k degenerate; the real eigenvectors used for display are the standing-wave combinations ckj ∝ cos(2πkj/N) and sin(2πkj/N). This reproduces the classic pictures — the Frost circle for rings (benzene's pattern at N = 6) and particle-in-a-box-like nodal counting along chains — while inheriting every approximation of the Hückel and frozen-orbital assumptions. Numbers here are indicative only.

12. Verification: what is checked and how

The verify page runs the numerical suite in your browser. Being precise about the claim: what is verified is the basis functions and their advertised mathematical properties — normalization, orthogonality, closed-form expectation values, node counts, symmetry identities, and agreement between independent implementations. What is only estimated — Slater Zeff, orbital energies, and everything in §§9–11 — is checked for internal consistency and honestly reported against reference values, but cannot be "verified" into being accurate physics.

Quadrature choices (implemented in quadrature.js):

  • Radial integrals: 64-node Gauss–Legendre on each of 8 equal subintervals of [0, rmax], with rmax from the orbital's suggested extent. The integrands are smooth and exponentially decaying; effective accuracy is ~10−12.
  • Angular integrals: 32-node Gauss–Legendre in x = cos θ crossed with a 64-point uniform trapezoid rule in φ. The φ integral annihilates every |m| ≠ |m′| pairing exactly (the trapezoid rule is exact for trigonometric polynomials below the Nyquist degree), and the surviving |m| = |m′| integrands are polynomials in x (the paired sin|m|θ factors combine into (1 − x²)|m|) of degree (l − |m|) + (l′ − |m|) + 2|m| = l + l′ ≤ 6 — far below GL-32's degree-63 exactness. The 16×16 Gram matrix of all real harmonics with l ≤ 3 is checked against the identity at tolerance 10−12.

Representative checks: radial-norm and radial-ortho (∫r²R² = 1 for every subshell with n ≤ 7, and cross-n orthogonality for five representative same-l pairs, 1s–2s through 4f–5f); laguerre-xcheck (Horner coefficients vs. an independent recurrence); the theory-anchors group (anchor-R10…anchor-R32 and anchor-Y00, anchor-pz, anchor-px, anchor-py, anchor-dz2: the code's generated formulas equal the textbook forms printed on this page, sampled pointwise); norm-3d (a full 3D ∫|ψ|² through the same code path the renderer uses); slater-regression (exact rational Zeff values, including the Fe example of §8); config-vs-aufbau (the authored configurations of all 118 elements equal the Madelung generator plus its documented exceptions); plus the limit checks of the speculative modules and a marching-cubes self-test that extracts an analytic sphere and compares surface area against 4πR². The "Verify this orbital" link in the app appends normalization, ⟨r⟩, node-count, and Zeff checks for the exact orbital being viewed.

Informational rows (Info) report honest deviations — Slater vs. Clementi–Raimondi screening, subshell non-orthogonality — without passing or failing: they are measurements of the model's limits, not test failures.
