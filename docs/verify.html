Verification suite

This page runs Valence View's numerical test suite in your browser — the same code that draws the orbitals, checked against closed-form mathematics by Gauss–Legendre quadrature. No server, no pre-computed results: every number in the table below is computed when you load the page.

What is verified, precisely: the basis functions and their advertised mathematical properties. Normalization (∫|ψ|² = 1), orthogonality within a shell, closed-form expectation values ⟨r⟩, radial/angular node counts, agreement between independent implementations (Horner-evaluated Laguerre coefficients vs. a three-term recurrence; generated symbolic formulas vs. the textbook tables printed on the theory page), Zeeman splitting symmetry, LCAO limiting behavior, and the marching-cubes surface extractor against an analytic sphere.

What is only estimated, and not "verified" into being accurate physics: Slater's Zeff and the orbital energies built from it. These are checked for internal consistency (exact rational regression values, configuration bookkeeping across all 118 elements), and their known deviations from SCF reference values (Clementi–Raimondi) are reported as informational rows — marked Info — which never pass or fail. The same applies to the speculative magnetic-field and LCAO models: their limits are checked, their accuracy is not claimed. See the theory page's limitations and verification sections for the full statement.

Opening this page with an orbital fragment in the URL — e.g. verify.html#Fe-3d_z2 from the app's "Verify this orbital" link — appends that specific orbital's checks (normalization, ⟨r⟩, node counts, Zeff, energy) to the full run.
